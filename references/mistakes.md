# Mistakes that cost real apps real time

Each entry: **mistake**, **symptom**, **fix**, and whether `check` can see it. Built from lessons shipping real embedded apps; observed between August and October 2026 and rewritten here in general terms. "Seen on" names the stack; treat other stacks as UNPROVEN.

| # | Mistake | Symptom | Fix | `check` |
|---|---|---|---|---|
| 1 | Hyphenated props in JSX (`list-slot="primary"`) copied from raw-HTML docs | `tsc` green, every gate green, desktop perfect; the phone layout silently lost on every table | camelCase: `listSlot`. TypeScript exempts hyphenated JSX names, so typecheck can NEVER prove a Polaris prop works | `kebab-prop` |
| 2 | Team notes asserted "attributes are kebab-case" as a verified fact | every page written from them was wrong | a claim of the form "X is always Y" about a vendor needs the vendor's own validator or docs; notes labelled verified spread the error to everyone who trusts them | n/a |
| 3 | Added `@shopify/polaris` (React) | works at first on an unmaintained library; the package is deprecated | web components only; keep `@shopify/polaris-types` | `polaris-react-import` |
| 4 | Edited tsconfig `types` and dropped `@shopify/app-bridge-types` | exactly ONE element (`s-app-nav`) fails "does not exist on type JSX.IntrinsicElements" | `types` is an allowlist; list `@shopify/polaris-types` AND `@shopify/app-bridge-types`. Do not bump the Polaris types | `tsconfig-types` |
| 5 | Boolean prop given `{false}` / a possibly-false expression (`checked={rule.enabled}`, `disabled={dirty}`, `hasNextPage={more}`) | React 18 writes `"false"`, Polaris treats a present attribute as true: a switched-off rule drawn ticked, buttons disabled on a clean form, a live Next button on the last page | `prop={cond \|\| undefined}` or `{...(cond ? { prop: true } : {})}` | `boolean-false-expr`, `boolean-string-false` |

| 7 | A `slot` the parent element does not implement (a button as a child of a section) | nothing renders; no error | read the parent's slot list; slotted nodes are DIRECT children | (NOT DONE) |

| 19 | A `loading="false"`-style string reaching a prop | the table stayed dimmed | omit the prop when false | `boolean-string-false` |

## The shape behind most of these

Four-fold: (a) the type system is satisfied by the shape while the constraint lives somewhere it cannot see; (b) the defect exists only at a width, a state, a locale or a speed nobody looked at; (c) the fix was verified in source, so the screenshot stopped being evidence and became a formality; (d) the correct step in each of two files produced a broken seam. The defence is not more care; it is a mechanical check where one is possible (`check`) and your own eyes, at 1280 and 390, where it is not.
