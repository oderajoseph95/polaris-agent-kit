# Screenshots we want

None are committed yet. Each row is one image to add by hand (real pages from a real embedded app, taken in the embedded admin, personal and store data removed or fictional). Name files `<page>-<width>.png`. Keep each under 400 KB (PNG, or WebP if the README links it that way).

| File | Page | Width | What it must show |
|---|---|---|---|
| `table-1280.png` | a records table | 1280 | header row, one-line rows, filters in the table, a badge column, pagination |
| `table-390.png` | the same table | 390 | the same rows as a list: title, then labelled fields, no horizontal scroll |
| `table-kebab-bug-390.png` | a table with `list-slot` (kebab) headers | 390 | the BUG: no labels / default layout, next to the fixed one |
| `table-filtered-zero-1280.png` | the table with a filter that matches nothing | 1280 | the filters still visible above an empty message and a Clear filters action |
| `modal-detail-1280.png` | a record modal | 1280 | heading, body blocks, actions in the footer slots |
| `modal-detail-390.png` | the same modal | 390 | one column, pinned header and footer |
| `states-grid.png` | a collage | 1280 | loading skeleton, healthy, partial, failed, unreachable, empty, filtered, each with its distinct sentence |
| `banner-one-slot-1280.png` | a page with a banner | 1280 | one banner listing several true conditions, with one action |
| `page-header-1280.png` | a page in the embedded admin | 1280 | title bar actions drawn by the admin, one primary action, section headers |
| `forms-savebar-1280.png` | a settings form | 1280 | the contextual save bar shown with unsaved changes |
| `check-output.png` | a terminal | n/a | `check` output with file:line and fix lines on a bad fixture |
| `doctor-output.png` | a terminal | n/a | `doctor` output showing pinned versus latest |

Before/after pairs are worth more than single shots: the "bug" images teach the mistake faster than prose.
